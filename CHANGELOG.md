# Changelog

## 1.3.1

### Added
- Add Minecraft target profiles for `1.21.x` and `26.1.x`.
- Add `-Pmc_target` support for switching build metadata and dependencies.
- Add 26.1.x compatibility metadata while compiling against Minecraft `26.1.2`.

### Changed
- Update Gradle wrapper to `9.4.0`.
- Keep original author credit as `netcatgirl (original mod creator)`.

### Fixed
- Disable Gradle Problems report generation to avoid VS Code Gradle sync failure on existing `problems-report.html`.
- Make Forge mod loaded check compatible with changed Forge APIs.
